# Data

`superstore.csv` is the Superstore sample dataset (9,994 order lines, 2014 to 2017). To use another file, put it here and pass `--data`.
It needs at least an **Order Date** and a **Sales** column; Order ID, Category and Region are optional.

`generate_sample_data.py` creates SYNTHETIC data only for checking that the code runs.
Never report results from the synthetic file.
